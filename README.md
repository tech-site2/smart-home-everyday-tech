# Smart Home & Everyday Tech

A polished, responsive editorial-style website for smart-home technology, everyday gadgets, reviews, buying guides, how-to content, AI & future tech, and deals.

## Current build
- Premium responsive homepage
- Sticky navigation and mobile menu
- Smart-home, gadget, review and buying-guide sections
- Search overlay with client-side article search
- Article preview modal
- Newsletter subscription interaction
- SEO metadata, robots.txt and sitemap
- GitHub Pages deployment workflow
- No framework or build step required

## Run locally
Open `index.html` in a browser, or serve the folder with any static HTTP server.

## Deployment
The repository includes a GitHub Actions workflow that publishes the site to GitHub Pages. After enabling Pages for the repository and selecting **GitHub Actions** as the source, pushes to `main` will deploy automatically.

## Production next steps
Connect a custom domain, analytics/consent platform, newsletter provider, CMS or database, affiliate product feeds, real editorial images, and a production search/indexing service before launch.
